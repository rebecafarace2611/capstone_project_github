# RFQC Report Figure and Table Format

Derived from `MScBA_CapstoneReport_StudentTemplate.docx`.

- Page: A4, single column.
- Margins: 4 cm left; 2.5 cm top, right, and bottom.
- Maximum full-width figure: approximately 14.5 cm (5.70 in).
- Body text: 12 pt Times New Roman, justified, 1.5 line spacing.
- Figure captions: numbered, placed below the figure, using the template's
  bold `Figcaption`/`Caption` style.
- Table captions: numbered and placed above the table using the bold
  `Tablecaption` style.
- Table body: 9 pt; column headings use the template's bold Arial table-header
  style.
- Figures: white background, restrained blue/grey palette, no internal figure
  title, and legible axis text at final inserted size.
- Tables: academic three-line format unless a full grid is required for
  comprehension.
